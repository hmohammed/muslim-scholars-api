# Attribution

The scholar biographies, teacher–student links, narrator grades and Arabic source excerpts served by this API were compiled by the Arees Institute and published on the Muslim Scholars Database at [muslimscholars.info](https://muslimscholars.info).

Each scholar response includes the original page URL. The site has been inactive since about 2012; this API is an independent republication, not an official Arees service.

## Takedown

If you are a rights holder and want a passage removed, contact the operator of this API with the scholar ID and the text in question. Source excerpts are kept so the compilation can be checked against the books they came from.
